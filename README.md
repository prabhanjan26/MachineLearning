# Machine Learning

A collection of hands-on Machine Learning implementations, experiments, and mini projects built while learning core ML concepts.

## Objective

Learn Machine Learning by understanding the theory, implementing algorithms, and applying them to real-world datasets.

## Workflow

* Learn the concept
* Explore the data
* Preprocess the dataset
* Train the model
* Evaluate performance
* Experiment and improve

## Topics

### Supervised Learning

* Linear Regression
* Logistic Regression
* K-Nearest Neighbors (KNN)
* Decision Trees
* Random Forest
* Support Vector Machines (SVM)
* Naive Bayes
* Ensemble Methods

### Unsupervised Learning

* K-Means Clustering
* Hierarchical Clustering
* DBSCAN
* Principal Component Analysis (PCA)

## Tools

* Python
* NumPy
* Pandas
* Matplotlib
* Scikit-learn


---

> *Learning by building, experimenting, and improving one model at a time.*
